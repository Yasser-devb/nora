# Changelog

## 0.1.1

- Configure Nora's `.nora` language icon for light and dark themes.
- Set the intended `morave-technologies` publisher ID while documenting that
  registration and maintainer control remain unverified.
- Clarify File Icon Theme precedence and how to select Nora Template Icons.

## 0.1.0

- Add Nora Template language recognition for `.nora` files.
- Add HTML-based syntax highlighting for Nora interpolation and include
  directives, plus snippets and basic editor configuration.
- Add Nora-branded extension icon and an optional file icon theme.
- Document local development, VSIX packaging, and current limitations.

This extension has not been published to the Visual Studio Marketplace.
